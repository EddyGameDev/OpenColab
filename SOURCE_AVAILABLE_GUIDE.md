# 📜 OpenColab Source-Available Guide

## Overview

OpenColab is published under a **Source-Available** model using the **PolyForm Noncommercial License 1.0.0**. 

Source-available means that the full, complete source code is public and open for inspection, modification, learning, and personal execution, while retaining clear noncommercial usage boundaries.

---

## 🟢 Permitted Uses (What You CAN Do)

You are freely permitted to do any of the following without payment or explicit permission:

- **Personal Coding & Projects**: Use OpenColab to code your personal apps, scripts, games, and side projects with OpenCode.
- **Academic & Independent Research**: Experiment with long-context LLMs (up to 1M tokens), test agent frameworks, and evaluate reasoning models.
- **Education & Learning**: Learn how cloud-tunneled LLM backends, FastAPI SSE proxies, and agent harnesses work.
- **Modifications & Customization**: Fork, customize, and adapt the scripts to support your own custom models, hardware setups, or agent workflows.
- **Internal Non-Profit Use**: Use OpenColab within registered non-profit, educational, or charity organizations.
- **Testing & Benchmarking**: Benchmark models against local or cloud hardware to understand how they perform.
